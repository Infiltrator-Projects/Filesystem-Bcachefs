# Bcachefs documentation installation

The documentation-only release owns exactly `/System/Resources/Documentation/Filesystem-Bcachefs.pdf`. Its source-downloading native RUN supports the same build-only and output options as other InfiltratorOS components. The amd64 DEB owns the PDF; normal Debian removal removes it. No filesystem implementation is built or installed by this release, and no runtime capability is claimed. Development qualification continues independently. A future qualified runtime release must supersede this documentation version and own the same PDF path.
